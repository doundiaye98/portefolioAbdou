# Portfolio - Abdou Ndiaye

## 🚀 Aperçu

Portfolio personnel moderne et responsive développé avec HTML5, CSS3 et JavaScript vanilla. Ce portfolio présente mes projets, compétences et expériences en tant que développeur Full Stack.

## ✨ Fonctionnalités

- **Design moderne et responsive** - Interface adaptative pour tous les appareils
- **Mode sombre/clair** - Toggle automatique avec sauvegarde des préférences
- **Animations fluides** - Transitions et effets visuels élégants
- **Navigation fluide** - Scroll smooth entre les sections
- **Formulaire de contact** - Interface interactive pour les messages
- **Intégration GitHub** - Liens directs vers mes projets et dépôts
- **Performance optimisée** - Chargement rapide et expérience utilisateur fluide

## 🛠️ Technologies utilisées

- **Frontend** : HTML5, CSS3, JavaScript ES6+
- **Design** : CSS Grid, Flexbox, Animations CSS
- **Icônes** : Font Awesome 6.0
- **Polices** : Google Fonts (Inter)
- **Responsive** : Mobile-first design

## 🚀 Installation et utilisation

1. **Cloner le repository**
   ```bash
   git clone https://github.com/doundiaye98/portefolio.git
   cd portefolio
   ```

2. **Ouvrir dans un navigateur**
   - Ouvrir `index.html` directement dans votre navigateur
   - Ou utiliser un serveur local (Live Server, XAMPP, WAMP, etc.)

3. **Personnalisation**
   - Modifier les informations personnelles dans `index.html`
   - Ajuster les couleurs dans `styles.css` (variables CSS)
   - Ajouter vos projets dans la section projets
